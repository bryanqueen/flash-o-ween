# ⚡ Tween Troubleshooting Guide

## Common Issues & Solutions

### Issue 1: "Both start and end frames must have content"

**Problem:** You're trying to create a tween but getting this error.

**Solutions:**

1. **Make sure you've drawn on BOTH frames:**
   ```
   ✅ Correct:
   - Go to Frame 0
   - Draw something (circle, rectangle, text, etc.)
   - Go to Frame 10
   - Draw something (same or different object)
   - Now create tween
   
   ❌ Wrong:
   - Go to Frame 0
   - Draw something
   - Try to create tween immediately (Frame 10 is empty!)
   ```

2. **Check the frame numbers in the timeline:**
   - Frames with content show a **✓** checkmark in the top-right corner
   - Empty frames show just the 🎬 icon
   - Make sure BOTH your start and end frames have the ✓

3. **Save your current frame:**
   - After drawing, click on another frame and back
   - This ensures your drawing is saved
   - Or just wait a moment before creating the tween

### Issue 2: Can't set end frame beyond certain number

**Problem:** When start frame is 0, end frame won't go past 9.

**Solution:** This was a bug - it's now fixed! You should be able to set:
- Start frame: 0
- End frame: Any frame up to the last one (e.g., 0-9, 0-20, 0-50, etc.)

**How to verify it's fixed:**
1. Open the tween panel
2. Set start frame to 0
3. Try typing a larger number in end frame (like 20)
4. It should accept it now!

### Issue 3: Tween creates weird results

**Problem:** Objects jump around or look strange.

**Solutions:**

1. **Match object count:**
   ```
   ✅ Good:
   Frame 0: Draw 1 circle
   Frame 10: Draw 1 circle (in new position)
   
   ❌ Bad:
   Frame 0: Draw 1 circle
   Frame 10: Draw 3 circles (system doesn't know which to match)
   ```

2. **Keep objects similar:**
   ```
   ✅ Good:
   Frame 0: Red circle
   Frame 10: Blue circle (color will transition)
   
   ⚠️ Tricky:
   Frame 0: Circle
   Frame 10: Rectangle (will morph, might look odd)
   ```

3. **Use appropriate easing:**
   - For smooth motion: Use "Ease In-Out"
   - For bouncing: Use "Bounce"
   - For constant speed: Use "Linear"

### Issue 4: Nothing happens when I click "Create Tween"

**Problem:** Button doesn't seem to work.

**Checklist:**
1. ✓ Did you draw on the start frame?
2. ✓ Did you draw on the end frame?
3. ✓ Is start frame less than end frame?
4. ✓ Did you wait for the "Creating..." message?
5. ✓ Did you check the timeline for new thumbnails?

**Debug steps:**
1. Look at the timeline - do both frames show thumbnails?
2. Click on start frame - do you see your drawing?
3. Click on end frame - do you see your drawing?
4. If either is empty, draw on it first!

### Issue 5: Frames are 0-indexed (Frame 0, not Frame 1)

**This is normal!** Frames start at 0:
- Frame 0 = First frame
- Frame 1 = Second frame
- Frame 9 = Tenth frame

**Why?** This is standard in programming and animation software.

## Step-by-Step Verification

### Before Creating a Tween:

1. **Check Frame 0 (or your start frame):**
   ```
   - Click on Frame 0 in timeline
   - Do you see your drawing on the canvas?
   - Does Frame 0 have a ✓ checkmark?
   ```

2. **Check Frame 10 (or your end frame):**
   ```
   - Click on Frame 10 in timeline
   - Do you see your drawing on the canvas?
   - Does Frame 10 have a ✓ checkmark?
   ```

3. **Create the tween:**
   ```
   - Click "⚡ Create Tween" button
   - Set Start Frame: 0
   - Set End Frame: 10
   - Choose easing
   - Click "Create Tween"
   ```

4. **Verify results:**
   ```
   - Look at timeline
   - Frames 1-9 should now have thumbnails
   - Click through frames to see the animation
   - Press Play to watch it!
   ```

## Common Mistakes

### Mistake 1: Not drawing on end frame
```
❌ Wrong:
1. Draw on Frame 0
2. Click "Create Tween"
3. Error!

✅ Correct:
1. Draw on Frame 0
2. Go to Frame 10
3. Draw on Frame 10
4. Click "Create Tween"
5. Success!
```

### Mistake 2: Trying to tween empty frames
```
❌ Wrong:
Frame 0: Empty
Frame 10: Empty
Create Tween → Error!

✅ Correct:
Frame 0: Has drawing ✓
Frame 10: Has drawing ✓
Create Tween → Success!
```

### Mistake 3: Start frame after end frame
```
❌ Wrong:
Start: 10
End: 0
→ Error: "End frame must be after start frame"

✅ Correct:
Start: 0
End: 10
→ Success!
```

## Quick Fixes

### Fix 1: "I drew something but frame still shows empty"
**Solution:** Click on another frame and back. This saves your drawing.

### Fix 2: "Tween looks choppy"
**Solution:** Use more frames (e.g., 0 to 30 instead of 0 to 10)

### Fix 3: "Objects don't line up"
**Solution:** Use the Select tool (V) to position objects precisely

### Fix 4: "Animation is too fast/slow"
**Solution:** Adjust FPS in the top menu (try 12 for classic animation)

## Testing Your Setup

### Simple Test:
```
1. Go to Frame 0
2. Draw a circle on the LEFT side
3. Go to Frame 10
4. Draw a circle on the RIGHT side
5. Click "⚡ Create Tween"
6. Set Start: 0, End: 10, Easing: Ease In-Out
7. Click "Create Tween"
8. Press Play

Expected: Circle moves smoothly from left to right!
```

If this works, your tween system is working correctly!
